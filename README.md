# SULTANOV BARBER

Сайт работает на Flask. Форма записи открывает WhatsApp с выбранными данными.

## Публикация через GitHub и Render

1. Создайте публичный или приватный репозиторий на GitHub.
2. Загрузите в него файлы `app.py`, `render.yaml`, `requirements.txt`, `static/` и `templates/`.
3. В Render выберите **New → Blueprint**, подключите GitHub-репозиторий и подтвердите создание сервиса `sultanov-barber`.
4. Render установит зависимости и запустит приложение по настройкам из `render.yaml`. После успешного деплоя откройте URL сервиса в панели Render — это будет публичная ссылка на сайт.

При каждом новом push в подключённую ветку Render сможет автоматически обновлять сайт. На бесплатном тарифе сервис может засыпать после периода бездействия, поэтому первый запрос иногда загружается дольше.

## Локальный запуск

```powershell
pip install -r requirements.txt
flask --app app run
```
