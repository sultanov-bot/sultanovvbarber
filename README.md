# SULTANOV BARBER

Сайт работает на Flask. Заявки резервируют свободный слот, затем открывают WhatsApp салона `996700656524` с именем и международным номером клиента, услугой, датой и временем. Клиент должен подтвердить отправку сообщения в WhatsApp.

Занятость хранится в PostgreSQL, заданной переменной окружения `DATABASE_URL`. Локально приложение использует SQLite в `instance/bookings.sqlite3`. Для бесплатного размещения PostgreSQL можно использовать Neon.

Прошедшие даты и время недоступны. Повторная запись на уже занятый слот отклоняется сервером и базой данных, даже если два клиента отправят форму одновременно.

## Публикация через GitHub и Render

1. Создайте бесплатный PostgreSQL-проект в [Neon](https://neon.tech/) и скопируйте строку подключения для базы. Включите SSL (обычно строка Neon уже содержит `sslmode=require`).
2. В Render откройте **Environment** у веб-сервиса и добавьте `DATABASE_URL` со строкой подключения Neon. Не публикуйте эту строку в GitHub. Для номера салона при необходимости задайте `WHATSAPP_NUMBER` цифрами с кодом страны, без `+`.
3. Подключите GitHub-репозиторий `sultanov-bot/sultanovvbarber`. Render установит зависимости и запустит приложение по настройкам из `render.yaml`.
4. После успешного деплоя проверьте ссылку сайта в панели Render. Новая версия запрашивает `DATABASE_URL` при каждом чтении или сохранении записей и явно сообщает об ошибке, если база не настроена.

При каждом новом push в подключённую ветку Render сможет автоматически обновлять сайт. На бесплатном тарифе веб-сервис может засыпать после периода бездействия, поэтому первый запрос иногда загружается дольше. У бесплатного тарифа Neon есть собственные ограничения и условия; актуальные лимиты проверьте в панели Neon.

## Локальный запуск

```powershell
pip install -r requirements.txt
flask --app app run
```
